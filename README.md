# E-Commerce Sales Analytics Dashboard

## 📌 Project Overview
This project analyzes online retail transaction data to uncover revenue trends,
customer behavior, and geographic performance using SQL and Power BI.

## 🛠 Tools & Technologies
- PostgreSQL (Data storage & SQL analysis)
- SQL (Aggregation, grouping, time-series analysis)
- Power BI (Data modeling, DAX, visualization)
- GitHub (Project documentation)

## 📊 Key KPIs
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value (AOV)

## 📈 Dashboard Features
- Executive KPI cards
- Monthly revenue trend analysis
- Top 10 customers by revenue
- Top 10 products by revenue
- Country-wise revenue visualization
- Interactive slicers (Country, Year, Month)

## 🧠 Business Insights
- Identified top-performing customers contributing a major share of revenue
- Observed strong revenue growth in later months
- UK contributes the highest share of total revenue
